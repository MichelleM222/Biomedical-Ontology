# Biomedical Ontology

## Project Overview

This project focuses on the design and development
of an ontology using semantic web technologies.

## Objectives

- Represent domain knowledge in a structured format.
- Define concepts, classes, properties, and relationships.
- Organize knowledge for semantic interpretation.
- Support knowledge querying and reuse.

## Technologies

- Protégé
- OWL (Web Ontology Language)
- RDF
- SPARQL
